    -財務風險檢測

     財務風險的定義

    風險是一體兩面的。一面是指可能會遭遇到的失敗或是損失的機率，相對的，另一面是指獲利的機會

    財務風險是指遭遇到金錢損失的機率或可能性

    財務風險的來源

    整體而言，財務風險的來源有以下幾個因素

    1. 市場價格的變化：如匯率、利率、商品價格等因素的變動
    2. 公司內部的變化：如內部組織、系統、人員、或流程等因素的變動
    3. 與同業間的交易：如同業之間衍生性商品的交易
    4. 與其他組織的交易：如與客戶或上游供應商的交易

    認識風險管理的定義

    1. 處理並評估金融市場所可能產生的風險，而事先制訂決策加以防範或降低風險的產生
    2. 盡量客觀的評估市場趨勢
    3. 利用分散投資來取代單一投資的高風險
    4. 善用金融工具來避險

    財務風險管理衍生性商品：

    1. 遠期合約
    2. 期貨
    3. 交換交易
    4. 選擇權

    財務風險管理的流程

    1. 評估可能面對的財務風險
    2. 設定可以接受的風險程度
    3. 制訂因應的風險管理策略
    4. 不斷檢測、控管及修

    進行的方式

    1. 對於所有的暴露進行事先的避險防範
    2. 利用衍生性商品來規避或減少現有的暴露風險
    3. 依循原訂的管理策略，接受所有可能產生的風險

    財務風險管理面面觀

    1.  遠期合約：遠期合約是指買賣雙方彼此同意在未來約定好的時間點完成交易，而交易的內容、日期與價格都己事  先確定好。

    EX：為確保十五個月後美國甲公司收到的餘款不會因匯率變動而貶值，此時它可以向金融機購買遠期合約，預先設定未來交割的日期與價格，建立一個放空部位，等之後收到餘款時當日再轉賣給該金融機構，變成作多部位。

    2.    期貨：它是由交易所制定、管理的標準定型化合約，原則上和遠期合約一樣，買賣雙方事先約定價格並在未來達 成交易。期貨交易功能很廣泛，不只能夠避險，還可以適時投機。整個期貨市場也只有少數避險者真正進行實物交割，其他都是為了賺取差價而進行的投機交易。期貨交易的避險與投機其實是一體兩面的事，端看交易者的心態及行  情是否對自己有利。

    3.  交換交易：是利用利率或貨幣的交換，來達到規避風險目的。

    遠期合約3個月=>1年 期貨

    在什麼情況下會使用到利率交換交易呢?

    銀行借款：500萬台幣

    借款期間：2年半

    貸款者1：甲公司=> 固定利率

    貸款者2：乙公司=> 浮動利率加上100個基點

    利率與貨幣的價值，會因為所處的國家不同而產生不同價值的差異，投資者便可以藉由這樣的差異，來進行風險的規避。

    4.  選擇權：選擇權是一種契約，可以用在規避任何投資組合的風險。

    如：期貨、利率、貨幣、股票、現金或商品等。

    一旦契約成立，契約到期日的價格就是投資的結果。

     選擇權= 契約

    EX：選擇權的交易方式：

    • 標的物：標的物之品質、數量、交割方式均必須明確規定
    • 履約價格：是指買賣雙方要履行標的物之價格
    • 權利期間：若98/1/1開始之選擇選，契約明定失效日為95/6/1，則此契約之權利期間為六個月。

    契約的買方在支付權利金之後，在未來的一段期間內，擁有以履約價格買入或出售一定數量標的物『權利』  

    分散風險的重要性

    1. 分散風險在投資管理中是不可或缺的一環
    2. 針對投資資產、供應商、客戶等各面向採取適當的風險分散策略
    3. 投資人千萬不要抱著僥倖的心理
    4. 事先妥善做好財務風險規劃，即使面臨風險的衝擊，才能有承受考驗的後
